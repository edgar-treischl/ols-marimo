OLS Regression with Palmer Penguins

An interactive Marimo app that teaches students the main principles of Ordinary Least Squares (OLS) regression using the Palmer Penguins dataset.

Learning objectives

- Understand the OLS model and the least-squares principle. Explore relationships between penguin measurements, such as flipper length and body mass or other measures.
- Interpret regression coefficients, predictions, and residuals.
- Evaluate model fit
- Examine regression assumptions, including residual normality and homoscedasticity.


The app combines data exploration, model estimation, visualizations, and statistical diagnostics to help students connect regression theory with practical analysis.


Run the browser-based app:

```bash
make serve
# http://localhost:8000
```


Edit the notebook locally:

```bash
make dev
```
